# Viewer models

## Project spacecraft

`detumble_3u.glb` is generated by `assets/scripts/create_detumble_3u.py` from
Blender primitives. It is the fallback spacecraft if ICECube cannot load. Body +Z is the
long axis, coordinates are meters, and the mesh does not set physical inertia.

## SUCHAI-II cutaway (reference asset)

`suchai_cutaway.glb` is the previous sidebar asset, retained for reference with its license. The viewer now draws a procedural hardware schematic and does not load or package this GLB. It adapts selected geometry from SPEL's
[SUCHAI-II CAD repository](https://github.com/spel-uchile/CAD_SUCHAI_II), revision
`cd587d140626b171df6efd11ef67736fa53c759e`. The source is
`CAD_Cubesat_3U.stp`; its SHA-256 is
`5043f93a30ce4c13d86d0ad10dcff5cfb669dde5504626a648fd1572b9ed8655`.
The repository's MIT license and copyright notice are retained in
`SUCHAI-II-LICENSE.txt`.

The adaptation keeps the ISIS 3U structure and selected lower electronics.
Exterior solar panels, antennas, small components, fasteners, and most of the
camera-facing side frame are omitted for visibility. The original assembly is
rotated into body axes, centered on the structure, and uniformly scaled to a
0.34 m frame length. Meshes are simplified for the sidebar graphic,
recolored, and given vertex colors for fixed directional shading. The current
asset contains 61 meshes and approximately 38,000 triangles.

In the former cutaway, live rods, mounts, wires, and the magnetometer were drawn by
`apps/rod_view.cpp` using the simulation's visual configuration. That combined
view was an educational adaptation, not the original SUCHAI-II hardware layout
or a mechanically verified design. The new schematic is independent of this
asset. Physics and inertia are unchanged.

Regenerate from the repository root with Python 3.12 and Blender 5.2:

```sh
python3.12 -m venv /tmp/detumble-cad-env
/tmp/detumble-cad-env/bin/python -m pip install cadquery-ocp==8.0.1.1.0
curl -fL https://raw.githubusercontent.com/spel-uchile/CAD_SUCHAI_II/cd587d140626b171df6efd11ef67736fa53c759e/CAD_Cubesat_3U.stp -o /tmp/detumble-suchai.stp
/tmp/detumble-cad-env/bin/python assets/scripts/convert_suchai_step.py /tmp/detumble-suchai.stp /tmp/detumble-suchai-mesh.json
blender --background --python assets/scripts/create_suchai_cutaway.py -- /tmp/detumble-suchai-mesh.json
```

The STEP input and intermediate JSON are intentionally not bundled. CAD tools
are required only for asset regeneration, not for building or running Detumble.

## NASA ICECube orbital exterior

`icecube_3u.glb` adapts NASA/Christopher R. Meaney's
[ICECube model](https://science.nasa.gov/3d-resources/cubesat-icecube/) and is the
default rotating spacecraft in the orbital view. It provides exterior geometry
with mission-specific apertures and panels. The sidebar independently draws a procedural schematic to expose the
simulated magnetic hardware. Neither visual
model determines the simulation's inertia or actuator configuration.

The source GLB uses Draco compression, which Blender decodes for raylib.
`assets/scripts/prepare_icecube.py` bakes the imported transforms, centers the
complete exterior, and uniformly scales its Z length to 0.34 m. Body +Z remains
the long axis. It preserves the source proportions and materials and exports
an uncompressed GLB. Source SHA-256:
`7ad1a4be4beb2c1b62b6fc48a9538db6c914d871099681745e188deb1925f31a`.

Regenerate from the repository root with Blender 5.2:

```sh
curl -fL 'https://assets.science.nasa.gov/content/dam/science/cds/3d/resources/model/cubesat---icecube/CubeSat%20-%20ICECube.glb' -o /tmp/detumble-icecube.glb
blender --background --python assets/scripts/prepare_icecube.py -- /tmp/detumble-icecube.glb
cmake --build --preset release
```

NASA makes its 3D resources available under its
[media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/).
`ICECube-NOTICE.txt` records the credit and adaptation and is packaged with the
runtime model. NASA endorsement is not implied. A comparison render is also
retained in `docs/media/icecube-preview.png`.
