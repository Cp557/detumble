# Magnetic-only validation

Results are generated by the native mission runner. This directory contains compact per-mission CSVs and independently recomputed aggregates; full-rate traces stay in ignored `runs/`.

## Reproduction protocol

Build the release preset. All recorded campaigns use:

| Setting | Value |
| --- | --- |
| Duration / physical timestep | 12,000 s / 0.02 s |
| Orbit | 500 km circular, 51.6 degrees |
| Initial speed | Uniformly sampled 5–15 deg/s |
| Initial attitude / tumble axis / orbit phase | Seeded randomized |
| Truth/reference field | IGRF-14 / IGRF-14 |
| Epoch | 2025-01-01T00:00:00Z |
| Sensor profile | Realistic; 10 Hz, 100 nT noise, 300 nT bias, 10 nT quantization |
| Magnetic rod limits | ±0.2 A m² per axis |
| Controller gain / B-dot filter | 50,000 / 0.2 s |
| Goal | ≤0.5 deg/s continuously for 30 s |
| Final verification | Last 300 s entirely ≤0.7 deg/s |
| Estimated-rate handoff | 30 s sustained confidence; rate uncertainty <0.05 deg/s |

These controller defaults were retained rather than optimized against holdout outcomes. The independent seed-2027 comparison is the designated holdout; seed-2025 is a separate development/check campaign. Scenario generation and paired controller runs use exactly the same initial state and sensor realization.

```bash
cmake --preset release
cmake --build --preset release
ctest --preset release --parallel 4

# Baseline deliberately disables the estimator to demonstrate B-dot alone.
./build/release/detumble_monte_carlo --runs 25 --seed 2026 --estimator off \
  --results runs/baseline25.csv --aggregate runs/baseline25_aggregate.csv
python3 assets/scripts/analyze_campaign.py runs/baseline25.csv \
  --output docs/validation/baseline25.csv \
  --aggregate docs/validation/baseline25_aggregate.csv

./build/release/detumble_monte_carlo --runs 15 --seed 2025 --compare \
  --results runs/development15.csv --aggregate runs/development15_aggregate.csv
python3 assets/scripts/analyze_campaign.py runs/development15.csv --paired \
  --output docs/validation/development15.csv \
  --aggregate docs/validation/development15_aggregate.csv

./build/release/detumble_monte_carlo --runs 100 --seed 2027 --compare \
  --results runs/holdout100.csv --aggregate runs/holdout100_aggregate.csv
python3 assets/scripts/analyze_campaign.py runs/holdout100.csv --paired \
  --output docs/validation/holdout100.csv \
  --aggregate docs/validation/holdout100_aggregate.csv
```

The actual holdout was processed in four independent 25-case slices with `--start-run 0`, `25`, `50`, and `75`. Merging with the analysis script sorts by run/controller, rejects duplicates, and verifies equal scenario parameters within each pair. Exactly the same case sequence is produced by the single 100-case command above.

CSV missing times are `-1`; unavailable estimation errors are NaN. Estimator convergence means first reported confidence; only sustained confidence permits handoff. Percentiles use the inclusive interpolation method. Dipole effort is the time integral of squared **applied** dipole, including coil-off sampling intervals. It is not electrical energy.

## Automated and manual checks

The 69-test suite covers frame/quaternion conventions, dynamics conservation, six independent IGRF Fortran fixtures, magnetic torque direction/limits, noise and sensor scheduling, single-vector/static-field ambiguity, arbitrary seeded estimator initialization, field-parallel rotation, PSD covariance, outlier rejection/reset, confidence loss and controller fallback, stale/saturated measurements, replay/reset, mission scoring, and representative B-dot missions.

CLI checks exercised invalid numeric/configuration inputs, full-rate CSV shape, reference-model/epoch option ordering, paired scenario identity, exact correspondence of sliced campaign rows, and trace filenames with nonzero run offsets. The coefficient generator reproduces its header exactly from the checksum-verified official table. The viewer was launched and its screenshot inspected; the regenerated Blender model loaded at the expected dimensions.

A separate 600 s seed-42 experiment used IGRF truth with a dipole navigation reference. The estimator briefly reported confidence but did not sustain it for the 30 s handoff. There was no advanced-controller activation and no `LOW_RATE` entry; all 30,000 true attitude/rate states matched a B-dot run exactly. This is a mismatch/fallback check, not a successful full detumble mission. It also illustrates why confidence is provisional rather than a universal accuracy guarantee.

```bash
./build/release/detumble --duration 600 --reference-field-model dipole \
  --estimator off --output runs/mismatch_baseline.csv
./build/release/detumble --duration 600 --reference-field-model dipole \
  --controller estimated-rate --output runs/mismatch_estimated.csv
```

Both debug and release builds passed all 69 tests locally on macOS. The debug suite took about 608 s; a release run under concurrent campaign load took about 15 s. The final epoch-validation checks also passed in debug after tightening the date parser. Viewer checks were performed on macOS. The CI workflow is configured to build/test macOS, Linux, and Windows. These recorded results are local macOS results; remote platform outcomes are not included in this validation record.

## Interpretation

The campaigns use matching navigation/main-field and inertia models. They validate the specified simulation envelope, not unknown initial rates, arbitrary navigation/inertia errors, external magnetic disturbances, or flight hardware. Full-attitude accuracy is secondary to detumbling and can degrade when magnetic geometry is weak. Rate-confidence calibration under model mismatch remains future work. B-dot remains the default and the estimated-rate controller is an optional experiment.

## Current viewer checks (2026-10-08)

occupies one quarter of the window; the orbital scene renders independently in
the remaining area.

simulation time. Component coordinates/dimensions are available on hover. There
are no activity-history strips, ON/OFF labels, or central reference-axis cross.

reset of time and activity. The latest related 14-test subset also passed,
